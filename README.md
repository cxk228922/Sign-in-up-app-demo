### 環境設定
此程式為基於C#編寫的.NET Maui App，並使用Visual studio 作為開發環境<br>
需安裝以下套件:<br>
* .NET desktop development
* .NET Multi-platform App UI development
* sqlite-net-pcl
* MailKit
* CommunityToolkit.Maui
### 警告
